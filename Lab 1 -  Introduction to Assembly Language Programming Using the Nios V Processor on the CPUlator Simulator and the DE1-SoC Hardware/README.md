# ECE243 Lab 1

This repository contains my solution for **Part III of the ECE243 Lab 1**, where I wrote and tested my first **Nios V Assembly Language** program.

## Description

The program calculates the sum of the numbers from **1 to 30** using a loop. The final sum is stored in register **`s1`**, and the program enters an infinite loop once the calculation is complete.
The program was developed and tested using **CPULator**, with single-stepping used to observe and verify the behavior of each assembly instruction.

## Concepts Practiced

- Nios V Assembly Language
- Registers and register operations
- Loops and branching
- Arithmetic instructions
- Program flow and infinite loops
- Debugging through single-stepping

## Expected Result

The final value stored in register `s1` is: 465.
