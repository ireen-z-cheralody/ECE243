# ECE243 Labs — RISC-V Assembly & C

This repository contains the labs I completed for **ECE243: Computer Organization** at the University of Toronto.

The labs involved programming on a **RISC-V processor** using **RISC-V Assembly Language** and **C**, with a focus on understanding low-level computer systems and how software interacts directly with hardware.

## Topics & Skills

- RISC-V Assembly
- C Programming
- Low-level programming
- Processor and memory interaction
- I/O and hardware interfacing
- Debugging and testing

## Repository Contents

Each folder contains the code and files for an individual ECE243 lab.

> Some lab files and supporting materials may be omitted due to course policies.
